# Research & Competitor Analysis

## The Rating System
We need to prompt users to rate spots on:
1. Noise level (Quiet/Chatter/Loud)
2. Outlets (Every table/Few/None)
3. Seating space (1-5 scale)
4. Busyness (Google Maps API)
5. Price range (Google Maps API)
6. Wi-Fi speed (Slow/Med/Fast)
7. Vibe/Aesthetic (Open text)
8. Hours (Google Maps API)

## Competitors
*   **Beli:** Great for food ratings, but not specifically for *studying*.
*   **Yelp:** Too broad, doesn't focus on Wi-Fi or outlets.
*   **Discord/Group Chats:** Good for friends, but no map/spot discovery.
