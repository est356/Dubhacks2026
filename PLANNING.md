# Project Planning & Scope

## 🎯 The "Locked" Idea
A study spot discovery app with social features and an AI chatbot.

## 👤 Target Audience
*   College students looking for good study spots.
*   Remote workers needing a change of environment.
*   Friends who want to co-work without a formal study group.

## 🏗️ Core Features (MVP)
*Must-Have for Demo:*
1.  **Interactive Map:** Open app to map with icons for cafes. Hover for images/ratings.
2.  **AI Chatbot (The Cute Cat):** User describes needs, AI recommends a spot. 
3.  **Search & Filter:** Filter by Wi-Fi, outlets, noise, seating, etc.
4.  **Save/Rate:** Save spots to favorites and leave a rating.
5.  **Friend Activity Feed:** See where friends are studying (statuses like "Studying for 8 hrs!") and a tiny Spotify icon.
6.  **Session Logging:** Manually log a study session with a photo and time.

## 🚀 Stretch Goals (If Time Allows)
*   Music sharing/rating API (Spotify Web API).
*   Study group creation.
*   Night Mode (focus on safety/late-night spots for the hackathon).
*   Receipts after logging a session (cute UI touch).

## 🚫 Cut List (Do NOT waste time on this)
*   Formal study group creation (Low priority).
*   Seeing real-time live locations (Security issue - instead use "Checked in at").
*   Pomodoro timer (Too generic, not a unique feature).
